## Алгоритм (по docs/patching.md)

1. `docker manifest inspect ...:8.7.1` → `EXISTS` (8.8.0 → `MISSING`)
2. Бэкап MongoDB → `bck/rocketchat-before-8.7.1-20260824.dump.gz` (5.1G); **ротация**: удалён старейший `8.6.0-20260706`, осталось 3 свежих
3. `docker pull ...:8.7.1` (digest `sha256:24aa0794...`)
4. Извлечь vanilla `app.js` (старый → `app.js.bak-8.7.0`)
5. Скрипт на сервере идентичен репо (`sha256 1b88d723...`); `sudo python3` → `patched ok (3 блок(ов))`, якоря **без изменений** (диапазон 8.5.0–8.7.1 стабилен), маркеры `rc-patch:`=2, `CYR_MAP`=6
6. `node --check` образом 8.7.1 → SYNTAX_OK
7. Dockerfile `FROM ...:8.7.1` (правка тега + комментария `sed` на сервере), `docker build --no-cache -t ...:8.7.1-patched`
8. Бэкап compose (`docker-compose.yml.bak-pre-8.7.1`), тег `8.7.1-patched`, `up -d rocketchat --force-recreate`
9. Проверка пройдена
