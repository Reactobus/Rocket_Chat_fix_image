# История обновлений Rocket.Chat

Хронология апгрейдов форкнутого (пропатченного) Rocket.Chat на хосте `Rocket_chat` (`srv771799`). Один файл — один цикл обновления.

## Как вести

- **Один цикл обновления = один файл.** Имя: `YYYY-MM-DD-<FROM>-to-<TO>.md` (напр. `2026-07-06-8.5.0-to-8.6.0.md`).
- Заполнять по шаблону [`_TEMPLATE.md`](./_TEMPLATE.md): дата, версии, инфраструктура, алгоритм, проверка, проблемы/решения, git, заметки на следующий цикл.
- **Создавать в конце каждого цикла** обновления (после успешного деплоя и проверки, вместе с коммитом изменений скрипта/Dockerfile/доков).
- Фиксировать честно: если был откат или частичный успех — так и писать, с причиной.
- Сам алгоритм обновления — в [`../docs/patching.md`](../docs/patching.md); здесь только журнал «что реально произошло в этот день».
