## Алгоритм (по docs/patching.md)

1. `docker manifest inspect ...:8.8.0` → `EXISTS`
2. Бэкап MongoDB → `bck/rocketchat-before-8.8.0-20260902.dump.gz` (5.1G); **ротация**: удалён старейший `8.6.1-20260716`, осталось 3 свежих
3. `docker pull ...:8.8.0` (digest `sha256:821324cc...`)
4. Извлечь vanilla `app.js` (старый → `app.js.bak-8.7.1`); бандл заметно вырос — **20.3 MB** против ~19.7 MB у 8.7.1
5. Скрипт на сервере идентичен репо (`sha256 1b88d723...`); `sudo python3` → `patched ok (3 блок(ов))`, якоря **устояли, несмотря на минорный бамп** (диапазон 8.5.0–8.8.0), маркеры `rc-patch:`=2, `CYR_MAP`=6
6. `node --check` образом 8.8.0 → SYNTAX_OK
7. Dockerfile `FROM ...:8.8.0` (правка тега + комментария `sed` на сервере), `docker build --no-cache -t ...:8.8.0-patched`
8. Бэкап compose (`docker-compose.yml.bak-pre-8.8.0`), тег `8.8.0-patched`, `up -d rocketchat --force-recreate`
9. Проверка пройдена
